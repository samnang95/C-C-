# 01 - Calculator

A C calculator project.

## Project Structure

```text
01-calculator/
├── build/          # Compiled binaries and object files
├── include/        # Header files (.h)
├── src/            # Source files (.c)
│   └── main.c
├── tests/          # Unit tests (.c)
│   └── test_main.c
├── .gitignore
├── Makefile
└── README.md
```

## Usage

```bash
# Build the executable (build/calculator)
make

# Build and run the program
make run

# Build and run unit tests
make test

# Remove compiled artifacts
make clean
```
